layers/ — first command to run at each checkpoint

L0 your access

  • API allow-list = bastion EIP/32
  • access entry for your principal
aws sts get-caller-identity
curl -4 https://checkip.amazonaws.com
kubectl config current-context

L1 controllers AWSISTIO

  • LBC: creds env present? region/VPC pinned?
  • ExternalDNS: filters include your zone?
  • istiod down ⇒ traffic flows, changes don't
kubectl logs -n kube-system deploy/aws-load-balancer-controller --since=15m | grep -iE 'error|denied'
aws eks list-pod-identity-associations --cluster-name istio-gateway-lab
istioctl proxy-status

L2 DNS AWS

  • ask the authoritative NS, not your cache
  • record must overlap the ALB's IPs
NS=$(dig +short NS $HOSTED_ZONE | head -1)
dig +short @$NS shop.$DOMAIN
dig +short $ALB

L3 ALB + TLS AWS

  • no ADDRESS ⇒ read Ingress events
  • all unhealthy ⇒ fail-open still serves
  • listener cert = Terraform ARN?
kubectl describe ingress edge-alb -n lab-gateway | sed -n '/Events/,$p'
TG=$(kubectl get targetgroupbinding -n lab-gateway -o jsonpath='{.items[0].spec.targetGroupARN}')
aws elbv2 describe-target-health --target-group-arn $TG --output table

L4 edge gateway ISTIO

  • Programmed=True, Service ClusterIP
  • attachedRoutes > 0
kubectl get gateway edge -n lab-gateway -o jsonpath='{.status}' | jq
istioctl proxy-config route deploy/edge-istio -n lab-gateway

L5 HTTPRoutes K8S

  • Accepted + ResolvedRefs per parent
  • duplicate hostname ⇒ oldest route wins ties
  • x-lab-rule tells you which rule matched
kubectl get httproute -A -o custom-columns=NS:.metadata.namespace,NAME:.metadata.name,HOSTS:.spec.hostnames,CREATED:.metadata.creationTimestamp
curl -sI https://shop.$DOMAIN/ | grep -i x-lab-rule

L6 Service → pods K8S

  • selector vs labels — case-sensitive
  • backendRef port = Service port
  • Istio does not validate the port in status
kubectl get svc podinfo-v2 -n lab-apps -o jsonpath='{.spec.selector}{"\n"}'
kubectl get endpointslices -n lab-apps -l kubernetes.io/service-name=podinfo-v2

L7 mesh ISTIO

  • istio-injection=enabled exactly, then restart
  • ambient: PROTOCOL HBONE
  • STRICT is enforced by the server side
kubectl get ns -L istio-injection -L istio.io/dataplane-mode -L istio.io/use-waypoint
istioctl ztunnel-config workload | awk 'NR==1 || $1=="ambient-lab"'
istioctl ztunnel-config service  | awk 'NR==1 || $1=="ambient-lab"'
